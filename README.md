Frontend, Database, Python, Backend를 시작으로

## 📝 Commit

| Type | 의미 |
| --- | --- |
| `✨ add` | 새로운 수업 내용 및 실습 코드 추가 |
| `🐛 fix` | 코드 오류 수정 |
| `♻️ refactor` | 기존 코드 구조 및 로직 개선 |
| `📝 docs` | README 등 문서 수정 |

```text
✨ add: Python 문자열 실습 추가
🐛 fix: 반복문 코드 오류 수정
♻️ refactor: 조건문 코드 개선
📝 docs: README 수정
```
